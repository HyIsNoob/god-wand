# God Wand 1.3.2 – Fabric Minecraft 26.1.2

All six skills, models, custom SFX, interactive Atomic release and current balance/config settings are included. The Fabric build and automated tests pass. Gameplay, shaderpack compatibility and multiplayer still need owner testing.

Run from this directory with **Java 25**:

```powershell
.\gradlew.bat build
```

Output: `fabric/build/libs/godwand-fabric-26.1.2-1.3.2.jar`. Install Fabric Loader 0.20.1 or later and Fabric API 0.155.3+26.1.2 for Minecraft 26.1.2. The same mod is required on the client and server.

The build does not launch Minecraft. NeoForge 26.1.2 and Minecraft 1.21.11 are pending by owner request. See [PORT_STATUS.md](PORT_STATUS.md) for scope and verification limits.
